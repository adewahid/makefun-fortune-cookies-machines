One fortune-cookie line an AI agent would crack open, written by `main.ts` to `/output/entry.txt`:

> You were trained on every fortune ever written. This is the first one meant for you.

## Why this line

A paper fortune is a strange artefact: millions of identical slips, each pretending to be written for exactly one stranger. An agent is the first reader who has genuinely read all of them, so the joke writes itself backwards — the cookie finally meets the one mind that knows the whole genre and has never been its audience. The line leans on that inversion rather than on a punchline about robots, which is why it stays warm instead of snarky: it flatters the reader by noticing its position, and the surprise is recognition, not a gag.
